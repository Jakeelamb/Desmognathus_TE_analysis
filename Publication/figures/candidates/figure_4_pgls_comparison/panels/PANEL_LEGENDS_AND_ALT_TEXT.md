# PGLS filtering comparison isolated panels

## a Current five-domain PGLS

Current branch: >=5 domains. Matched PGLS panels compare the same 19 species with estimated genome size in both branches, using the original branch lengths of the shared supplied dated phylogeny. Each point represents one species median; element counts do not act as regression weights. Both panels use the same log axes and fit log10(median ratio) ~ log10(genome Gbp), with maximum-likelihood Pagel lambda constrained to [0,1]. Each branch is refitted independently. Blue lines are back-transformed geometric fits; ribbons are 95% t coefficient intervals (17 degrees of freedom), not individual-species prediction intervals. Gray bars are genome-size and element-bootstrap median intervals. The fitted line and its interval do not propagate measurement error or tree uncertainty. The supplied tree's publication and calibration provenance remain unresolved. Primary medians and intervals are preserved exactly from S15. Four-domain medians are calculated on untransformed ratios, and new 95% percentile intervals use 2,000 within-species element-bootstrap replicates with deterministic per-species R seeds. The statistical bootstrap method matches the primary release, while the R random-number stream differs from the released NumPy PCG64 stream. Seeds and methods are recorded in species_summaries.csv. Elements are not biological replicates; these intervals describe the recovered-element sample. Review-only comparison; the four-domain branch is a sensitivity analysis, not a replacement release. The same >=3,000-bp LTR/Gypsy selection, exact annotation join and >=80% positive-depth coverage in each of the two LTRs and internal region are required. Within-species two-sided 1.5-IQR fences are calculated on each branch's eligible raw ratios before intersecting with coverage. The corrected domain-token count is used throughout. The broader branch changes the reference-element selection; its structural validity remains to be assessed. The depth ratio is a mapping/deletion-footprint proxy, not a deletion rate or direct solo-LTR count. Genome sizes are D. fuscus assembly-anchored IOD-derived estimates, converted at 0.978 Gbp per pg.

**Alt text:** Current five-domain PGLS Two matched scatterplots show the same 19 species, estimated genome size and median LTR ratio, with separate Pagel-lambda fits for five-domain and four-domain element selection. Each panel shows all species labels, measurement intervals and a blue confidence ribbon.
