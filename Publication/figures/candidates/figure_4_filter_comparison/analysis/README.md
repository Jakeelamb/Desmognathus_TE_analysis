# LTR domain-filter visual comparison

The current >=5-domain branch contains 380 elements, and the >=4-domain sensitivity contains 989, across the same 30 species in canonical supplied-tree order. Both panels have identical 0.025-2.5 ratio axes in log2 space, equal-width trimmed violin outlines and the same density bandwidth estimated from the original 380 observations. Hollow points are every retained element; vertical blue bars are species medians and horizontal blue lines are bootstrap intervals. Vertical jitter does not alter ratios. The dotted line means equal depth. Counts appear at right. In standalone exports, right-hand labels also give estimated genome size in Gbp. Broader domain eligibility with recalculated IQR fences adds 611 elements and excludes two previously retained elements, for a net gain of 609. Primary medians and intervals are preserved exactly from S15. Four-domain medians are calculated on untransformed ratios, and new 95% percentile intervals use 2,000 within-species element-bootstrap replicates with deterministic per-species R seeds. The statistical bootstrap method matches the primary release, while the R random-number stream differs from the released NumPy PCG64 stream. Seeds and methods are recorded in species_summaries.csv. Elements are not biological replicates; these intervals describe the recovered-element sample. Review-only comparison; the four-domain branch is a sensitivity analysis, not a replacement release. The same >=3,000-bp LTR/Gypsy selection, exact annotation join and >=80% positive-depth coverage in each of the two LTRs and internal region are required. Within-species two-sided 1.5-IQR fences are calculated on each branch's eligible raw ratios before intersecting with coverage. The corrected domain-token count is used throughout. The broader branch changes the reference-element selection; its structural validity remains to be assessed. The depth ratio is a mapping/deletion-footprint proxy, not a deletion rate or direct solo-LTR count. Genome sizes are D. fuscus assembly-anchored IOD-derived estimates, converted at 0.978 Gbp per pg.
