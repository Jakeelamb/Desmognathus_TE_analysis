# Direct and indirect path candidate

Reference-style candidate depicting direct and indirect paths under a specified genome-first causal hypothesis: genome -> cell, cell -> nucleus and genome -> nucleus. Component equations are cell ~ genome and nucleus ~ genome + cell, fitted with Pagel-lambda phylogenetic regressions on log10-transformed, sample-standardized traits from 24 species. Coefficients and normal 95% intervals come unchanged from frozen S28: genome -> cell beta = 0.716664 (0.425232 to 1.008097), cell -> nucleus conditional on genome beta = 0.573623 (0.073748 to 1.073498), and genome -> nucleus conditional on cell beta = 0.007923 (-0.491952 to 0.507798). The cell-to-nucleus coefficient differs from the previous two-edge chain because this model additionally adjusts nucleus area for genome size.
