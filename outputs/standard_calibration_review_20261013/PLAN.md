# Standard calibration review

This phase continues publication preparation against HEAD `15dfb3c18755cc8659b626fa213087c62c6db02f` and the preserved dirty working tree. Original scientific data, author documents, selected figures, and the frozen submission-preparation package remain protected. New work belongs in this directory.

The done predicate is a reproducible account of the standard discrepancy, an evidence-based decision on whether the designated images support recalibration, and a checked record of what still prevents a validated absolute scale. A failed or unavailable standard check remains visible. No reference value is selected by agreement with the desired result.

## Investigation steps

1. Route through the **how** skill. For motivation questions, also route through the **why** skill.
2. Throughput checkpoint stays one line: `throughput checkpoint: n/a, read-only investigation`.
3. Produce the `how`-shaped output (Overview / Key Concepts / How It Works / Where Things Live / Gotchas), or a recommendation with a tradeoffs table if the request is a decision between alternatives.
4. Apply the **unslop** skill to the reply.

The how exploration is partitioned into existing measurement flow, source-image and quantitative inventory, and primary-source DNA-content anchor evidence. The why route is skipped because this phase concerns measurement validity rather than design motivation.

## Workflow for any justified remeasurement

1. Read the Principles section of the **poteto-mode** skill.
2. Phase A: Frame.
3. Phase B: Design the workflow.
4. Phase C: Run the loop.
5. Phase D: Keep the audit trail.
6. Phase E: Verify and hand back.

The concrete units are ordered as follows.

- Reconstruct the existing standard and target summaries from retained tables and pin the source bytes.
- Trace the exact target measurement and review rules, rather than treating all archived IOD tables as equivalent.
- Inspect available standard source images, masks and acquisition metadata. Identify unknowns before interpreting a difference.
- If the genuine inputs and existing pipeline permit bounded remeasurement, execute it only into a new directory. Compare a real target control and a standard using the same measurement function before broader execution. Do not infer manual acceptance from automated eligibility.
- Review the assembly-derived anchor against primary sources. Keep it conditional unless independent DNA-content evidence is established for the standard.
- Prepare a source-linked Methods update for the confirmed single-run fact and the resulting calibration decision. Keep the online manuscript and frozen preparation unchanged.
- Independently verify the final evidence, limitations and protected-input hashes.

Scope comprises two designated standards, four existing target-reference images, up to three recorded alternate standard acquisitions, and the two distinct retained measurement paths. No HPC run, segmentation retraining, scientific model refit, figure regeneration, or cloud edit is planned. Any local execution needs bounded inputs and retained command, exit, clock and raw output.
