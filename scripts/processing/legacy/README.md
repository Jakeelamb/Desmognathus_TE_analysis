# Legacy processing code

These scripts are retained for provenance and are not part of the current
collaborator-review workflow.

- `build_analysis18_presentation_notebooks.py` generated the superseded
  `notebooks/presentation/` tree. Its analysis code is preserved here, but the
  canonical seven-notebook bundle is generated by
  `../build_research_review_notebooks.py`.

Do not use legacy outputs as current results unless they are independently
re-audited against the active TE34, Cell21, genome20, and path18 contracts.
