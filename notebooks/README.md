Open [`research_review/README.md`](research_review/README.md) first. It defines
the only collaborator-facing sequence:

3. TE34 repeat analysis;

Each canonical notebook is already executed and retains its displayed tables and
figures. Compact dependencies live under `results/data/research_review/` and
`results/figures/research_review/`; notebook folders do not contain duplicate
data, figure, HTML, or source/executed render trees.

`Desmognathus_publication_audit_analysis18_v1.ipynb` is the older combined audit
workbench. Keep it for cross-domain provenance, but do not use it as the primary
