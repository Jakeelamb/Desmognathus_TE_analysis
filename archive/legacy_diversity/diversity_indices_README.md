# Diversity Indices for Transposable Elements

This directory contains scripts for calculating and visualizing diversity indices (Shannon and Simpson) for transposable element data.

Legacy note:
These standalone scripts support older exploratory figure workflows. The
canonical diversity summary tables used by the current repo pipeline are
generated by `scripts/processing/diversity_stats.py`.

## Scripts Overview

### 1. diversity_indices_processor.py

A Python script that calculates Shannon and Simpson diversity indices from TE data.

**Features:**
- Loads TE data from a CSV file
- Filters columns to only include percentage data
- Calculates Shannon diversity index for each species
- Calculates Simpson diversity index for each species
- Exports results to CSV files for further visualization

### 2. diversity_indices_visualizer.R

An R script that creates visualizations from the calculated diversity indices.

**Features:**
- Creates bar plots for Shannon diversity index
- Creates bar plots for Simpson diversity index
- Creates a combined plot with both indices
- Creates a correlation plot between Shannon and Simpson indices
- Creates a heatmap visualization of diversity indices
- Calculates summary statistics and correlation between indices

## Usage Instructions

### Python Processing Script

```bash
# Basic usage
./diversity_indices_processor.py -i <input_csv_file> -o <output_directory>

# Example
./diversity_indices_processor.py -i /home/jake/Projects/dnaPipeTE/dnaPipeTE_Trinity_master_tbl_with_species.csv -o /home/jake/Projects/dnaPipeTE/Figure_datasets
```

This will generate three CSV files in the output directory:
- `shannon_diversity.csv`: Shannon diversity index for each species
- `simpson_diversity.csv`: Simpson diversity index for each species
- `combined_diversity.csv`: Both indices combined in a single file

### R Visualization Script

```bash
# Basic usage
./diversity_indices_visualizer.R -d <data_directory> -o <output_directory>

# Example
./diversity_indices_visualizer.R -d /home/jake/Projects/dnaPipeTE/Figure_datasets -o /home/jake/Projects/dnaPipeTE/Figure_datasets/Plots
```

This will generate several visualization files in the output directory:
- `shannon_diversity_plot.png`: Bar plot of Shannon diversity index
- `simpson_diversity_plot.png`: Bar plot of Simpson diversity index
- `diversity_indices_plot.png`: Combined plot with both indices
- `diversity_correlation_plot.png`: Scatter plot showing correlation between indices
- `diversity_heatmap.png`: Heatmap visualization of diversity indices

## Interpreting the Results

### Shannon Diversity Index
- Measures both richness and evenness of TE distribution
- Higher values indicate greater diversity
- Formula: H' = -Σ(p_i × ln(p_i))

### Simpson Diversity Index
- Measures probability that two randomly selected elements belong to different categories
- Higher values (closer to 1) indicate greater diversity
- Formula: D = 1 - Σ(p_i²)
