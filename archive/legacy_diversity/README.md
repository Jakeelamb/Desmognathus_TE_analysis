# Legacy Diversity Archive

This folder contains older exploratory diversity scripts that are no longer
part of the active Desmognathus TE processing pipeline.

Current canonical path:

- `scripts/processing/diversity_stats.py`

Non-destructive verification path:

- `path_analysis/scripts/build_canonical_diversity_tables.py`

Why these files were archived:

- they are not referenced by the current TE processing or path-analysis
  workflow
- some use older or inconsistent Simpson definitions
- keeping them in the active script paths made the diversity-generation path
  look ambiguous

These files are preserved for historical reference only.
